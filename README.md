## Run it

```sh
node main.ts
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (and `/output/entry.txt` when writable), then prints it. A candidate over 200 characters is refused with exit 1: `node main.ts "$(python3 -c 'print("x"*201)')"`.
